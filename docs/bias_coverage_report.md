# 커버리지·편향성 점검 리포트 (보고서 Ⅴ-2 부속)

작성일: 2026-08-10. 서비스 데이터가 어느 지역·항목에 치우쳐 있는지 점검하고,
그 한계를 이용자에게 어떻게 고지하며 어떤 순서로 해소할지 기록한다.

## 1. 커버리지 현황

| 데이터 | 커버리지 | 비고 |
|---|---|---|
| 발전소(10MW+) | 481개소 — 발전5사·한수원 전수 + 민간 주요 설비 | EPSIS 기준 100% |
| 발주법 주변지역 판정 | 전국 읍면동 1,346개 (반경 5km 산정) | 좌표 근사 발전소는 '근사' 표기 |
| 지자체 전입·정착 시책 | **73 / 226 시군구 (32.3%)**, 298개 사업 | 인구감소지역 26곳 포함 |
| 해외사업 | 발전5사 공개 사업 전수(각사 홈페이지·보도) | 지분율 일부 미공개 |

## 2. 확인된 편향과 근거

### ① 시책 데이터의 '발전소 소재지 우선' 편향 (의도된 우선순위)
- 시책 수집은 **발전소 소재 시군구부터** 진행 — 서비스 핵심 이용자(발전소 주변지역
  주민·전입 검토자)와 겹치는 지역을 우선한 것.
- 부작용: 발전소가 없는 시군구(대도시 자치구 등)의 시책은 미수록 → 해당 지역
  이용자에게는 "정보 없음"이 "혜택 없음"으로 오해될 수 있음.
- **완화 조치(적용됨)**: 미수록 지역 선택 시 "아직 수집되지 않았습니다(주요 발전소
  소재 시군구부터 제공 중)" 문구로 수집 범위를 명시(BenefitPanel). 챗봇도 데이터에
  없으면 '확인되지 않음'으로 답하고 관할 지자체 확인을 안내.

### ② 수도권/비수도권 분포
- 시책 수록 73곳 중 인구감소지역이 26곳(35.6%) — 전국 인구감소지역 89곳 대비 29.2%.
- 발전소 소재지 특성상 비수도권 군 단위가 상대적으로 많음. 이는 서비스 목적
  (기후 전환 × 지역 소멸 현장 안내)에 부합하는 방향의 치우침이나, 잔여 인구감소지역
  63곳이 미수록 상태.

### ③ 시책 항목 구성
- 카테고리 분포는 전입정착·출산육아가 다수 — 지자체 공고 자체의 구성을 반영.
- 청년일자리 등은 공고가 산발적이어서 누락 가능성이 상대적으로 높음(파이프라인
  키워드에 청년 포함으로 완화).

## 3. 해소 계획 (AI 파이프라인과 연동)

1. **1순위**: 미수록 인구감소지역 63곳 — 시드 URL 등록 → AI 파이프라인으로 확장
   (목표 73 → 120+ 시군구, kpi.md 지표).
2. **2순위**: 발전소 소재하지 않는 도 단위 시·군.
3. 대도시 자치구는 시 단위 시책으로 폴백(이미 구현: `sigungu.startsWith` 매칭).
4. 분기마다 본 리포트의 커버리지 표를 갱신하고, 미수록 지역 안내 문구를 유지한다.

## 4. 판단 기준 요약

- **커버리지 부족은 숨기지 않고 화면에 고지한다** (미수록 ≠ 혜택 없음).
- 수집 우선순위는 서비스 목적(발전소 주변지역·인구감소지역)에 따르되,
  그 기준 자체를 본 문서로 공개한다.
- AI 확장 시에도 지역 간 순서는 위 해소 계획을 따르고, 반영은 HITL 승인 후에만.
