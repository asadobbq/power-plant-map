# "우리동네 AI 안내" 안전장치 목록 (보고서 Ⅴ-3)

사이트 보유 데이터(발전소 481·지자체 시책 298건)를 그라운딩한 질의응답.
RAG-lite 구조(벡터DB 없음): 질문에서 지역·발전소명을 사전 매칭해 **해당 레코드만** 컨텍스트로 주입.

## 안전장치 목록표

| # | 위험 | 장치 | 구현 위치 |
|---|---|---|---|
| 1 | API 키 유출 | 키는 서버 환경변수(`ANTHROPIC_API_KEY`)로만 존재 — 클라이언트·저장소 비노출. 위젯은 서버리스 프록시(`/api/ask`)만 호출 | `web/api/ask.js` |
| 2 | 비용 폭주 | IP(해시)당 **분당 5회·일 50회** 제한(Redis). 키·Redis 미설정 시 챗봇 자체를 503으로 비활성(제한 없이 공개 금지). 질문 300자 제한, 출력 1,024토큰 제한. 시스템 프롬프트 캐시(prompt caching). 모델은 `CHAT_MODEL` 환경변수로 조정 가능 | `web/api/ask.js` |
| 3 | 환각(없는 정보 생성) | ① 주입된 데이터에 근거해서만 답변 ② 데이터에 없으면 "확인되지 않음" + 관할 문의처 안내 ③ 구조화 출력(JSON 스키마)으로 answered 여부를 모델이 자가 표기 | 시스템 프롬프트 규칙 1 |
| 4 | 금액·일정 오해 | 기준일을 컨텍스트에 주입하고 "변동 가능" 표기를 규칙화. 위젯 상단에 "참고용·법적 효력 없음" 상시 고지 | 규칙 2 + `AiChat.tsx` |
| 5 | 출처 불명 | 답변에 출처 표기 규칙 + 위젯이 컨텍스트에 실제 포함된 source URL만 출처 카드로 표시(모델 생성 URL 미사용) | 규칙 3 + `sources` 필드 |
| 6 | 프롬프트 인젝션·주제 이탈 | 질문·데이터 내 지시문 무시 규칙, 서비스 범위 외 질문 거절. 모델 안전장치 거절(`stop_reason: refusal`)도 별도 처리 | 규칙 5 + refusal 분기 |
| 7 | 개인정보 | 질문 **원문을 저장하지 않음** — 통계는 건수·응답시간·응답유형만(Redis 일별 카운터). IP는 해시로만 속도제한에 사용. 위젯에서 개인정보 입력 자제 안내 | `ask.js` 통계부 + 고지문 |
| 8 | 법률 자문 오인 | "법률·투자 자문 아님" 규칙 + 위젯 고지 | 규칙 4 |
| 9 | 장애 전파 | 프록시 오류 시 위젯이 폴백 문구("지도·혜택 탭 이용 안내")를 표시 — 서비스 본체(지도·데이터)는 무영향 | `AiChat.tsx` 오류 분기 |
| 10 | 효과 측정 | GA4 `ai_chat_ask{answered}` · `ai_chat_feedback{helpful}` · `ai_chat_error` — 응답률·만족도 KPI 집계(질문 내용 미수집) | `AiChat.tsx` |

## 시연 시나리오 3종 (발표 PPT용)

### ① 하동 주민 — "하동 살면 무슨 혜택 받아요?"
- 기대 동작: 하동군 매칭 → 하동빛드림본부(발주법 주변지역·전기요금보조) + 하동군 전입·정착
  시책(8건) 컨텍스트 주입 → 두 제도가 별개임을 구분해 안내, 출처 카드에 하동군청 URL 표시.
- 확인 포인트: 금액에 기준일·변동 가능 문구, "📍 하동" 칩 클릭 시 지도 이동.

### ② 전입 희망자 — "삼척으로 이사가면 지원금 있나요?"
- 기대 동작: 삼척시 시책(7건 — 전입지원금·출산 등) 근거 답변 + 신청 자격은 시청 확인 안내.
- 확인 포인트: answered=yes 이벤트, 출처 링크가 삼척시청 도메인.

### ③ 폐지 일정 문의 — "태안 화력 언제 폐지돼요?"
- 기대 동작: 태안발전본부 호기별 폐지 계획(#1 2025 → #8 2037, LNG 대체 포함) 답변 +
  "제11차 전력수급기본계획 기준, 변동 가능" 표기.
- 확인 포인트: 데이터에 없는 질문(예: "주가 전망")으로 이어가면 거절 + 범위 안내.
